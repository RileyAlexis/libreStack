# Libre Stack

Self-hosted server for DRM free epubs with an offline capable Progressive Web App front end. Librestack hosts your ebooks on your hardware with no tracking, ads or stores.

## Getting Started

Install from Source

```
git clone https://github.com/RileyAlexis/libreStack
```

Install Docker Compose[https://docs.docker.com/compose/install/linux/]

```
sudo apt-get update
sudo apt-get install docker-compose-plugin
```
